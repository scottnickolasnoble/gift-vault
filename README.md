# Gift Idea Vault

Remember what the people you love would like.

**V3** adds accounts and a database: sign in on any device and see the same people, ideas and occasions.

- **Home:** what's next, what's coming up, and who still needs a gift
- **People:** grouped by family, friends and work, with upcoming events and idea counts
- **Occasions:** birthdays plus anything you add (Christmas, Secret Santa…), with budgets, spending, and a To buy / Done plan for groups
- **Ideas:** tagged to an occasion, with status (Idea → Bought → Wrapped → Given)

Built with plain HTML, CSS and JavaScript, a small Node server, and Postgres (Neon). Hosted on Render.

To run it or put it online, see **[DEPLOY.md](DEPLOY.md)**.
